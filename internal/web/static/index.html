Virtual desktops

Windows keeps one saved wallpaper per desktop and swaps it in when you switch, which would replace Spanwall's per-monitor slices. Spanwall clears those and applies each desktop's wallpaper itself.

Wallpaper folder

Layouts

Each layout remembers which monitors it has. With auto switch on, plugging monitors in or out activates the saved layout made for exactly those monitors and re-applies the wallpaper.

Monitor setups

Each set of monitors you use (docked, laptop only, …) remembers its layout and wallpaper. When you dock or undock, that setup comes back as you left it. A setup is saved whenever you apply a wallpaper with it.

Smart framing

Applies to images you haven't framed yourself with Move image. Auto frame in the editor goes back to it after you have.

Windows look

Day and night

Rotate through the Day folder by day and the Night folder at night (add wallpapers to them in the Library). The wallpaper changes when day turns to night and back; with the slideshow on, it rotates within the current folder. The Day/night button in the Library turns this on and off.

Other wallpaper sources

Download new images into the wallpaper folder (checked every 6 hours, never deletes). Only landscape images at least the minimum width are kept.

Span groups

Span some monitors together and give the rest their own image. Monitors in the same group share one image; "Own image" gets a separate one. Used when applying "as span groups" and by the slideshow.

Startup, tray and hotkeys

Like ctrl+alt+pgdn. Needs ctrl, alt or win. Leave empty to turn one off.

Wallhaven account

For your collections (favorites) in the Wallhaven tab. The username shows public collections; the API key (from your Wallhaven account settings) also shows private ones. The key is saved only on this PC, sent as a header, and never shown again.
